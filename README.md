# FridaMusic Desktop

by Frida Labs

Este repositorio público contiene exclusivamente las releases oficiales de FridaMusic Desktop: instaladores, archivos de actualización de `electron-updater`, blockmaps, notas de versión y archivos de código fuente correspondientes a cada versión.

**No se usa este repositorio para desarrollo.** El desarrollo permanece en un repositorio separado y privado. Las versiones publicadas aparecen en [Releases](https://github.com/jagrdev-MX/FridaMusic-Desktop-Releases/releases).

FridaMusic Desktop deriva de Glassy Music y se distribuye bajo GPL-3.0. Cada release binaria debe incluir un asset `FridaMusic-Desktop-Source-VERSION.tar.gz` con la licencia, avisos y créditos pertinentes. Los archivos «Source code» generados automáticamente por GitHub para este repositorio de distribución no son el código fuente de la aplicación.

## Windows

FridaMusic Desktop actualmente se distribuye sin firma digital Authenticode para Windows. Debido a ello, Microsoft Defender SmartScreen puede mostrar advertencias de reputación para versiones nuevas: el ejecutable es nuevo, tiene un hash nuevo o todavía no ha acumulado suficiente reputación. Una advertencia de reputación no significa por sí sola que la aplicación contenga malware. Descarga FridaMusic únicamente desde las [releases oficiales de Frida Labs](https://github.com/jagrdev-MX/FridaMusic-Desktop-Releases/releases).

## Privacidad y soporte

FridaMusic Desktop funciona principalmente de forma local y actualmente Frida Labs no utiliza un sistema propio de telemetría o analytics para recopilar información sobre el uso de la aplicación. Algunas funciones pueden comunicarse directamente con servicios externos necesarios para su funcionamiento, sujetos a sus propias políticas.

Para dudas sobre seguridad, privacidad o funcionamiento de FridaMusic Desktop, incluidas sus conexiones externas, la información procesada, el código, los instaladores y el updater, puedes escribir a [fridalabs.soporte@gmail.com](mailto:fridalabs.soporte@gmail.com).
