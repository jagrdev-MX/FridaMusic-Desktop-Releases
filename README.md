# FridaMusic Desktop

by Frida Labs

Este repositorio público contiene exclusivamente las releases oficiales de FridaMusic Desktop: instaladores, archivos de actualización de `electron-updater`, blockmaps, notas de versión y archivos de código fuente correspondientes a cada versión.

**No se usa este repositorio para desarrollo.** El desarrollo permanece en un repositorio separado y privado. Las versiones publicadas aparecen en [Releases](https://github.com/jagrdev-MX/FridaMusic-Desktop-Releases/releases).

FridaMusic Desktop deriva de Glassy Music y se distribuye bajo GPL-3.0. Cada release binaria debe incluir un asset `FridaMusic-Desktop-Source-VERSION.tar.gz` con la licencia, avisos y créditos pertinentes. Los archivos «Source code» generados automáticamente por GitHub para este repositorio de distribución no son el código fuente de la aplicación.
